# AGENTS.md

This repository is oBusk's personal collection of agent skills, installable
with [`pnpx skills`](https://npmx.dev/package/skills). Each skill lives in its
own directory under `skills/` as a `SKILL.md` with YAML frontmatter (`name`,
`description`) and instructions in the body. See `README.md` for install
usage and the list of skills.
